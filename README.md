# Am-I-Ai 🧠👤

A mini-game that challenges players to determine how "human" or "AI-like" their answers are.

This app is designed to simulate and evaluate human reasoning patterns through interactive questions and custom scoring logic.

## 🔍 Features

- Built with **React**, **TypeScript**, and **Tailwind CSS**
- Game logic modeled around "human vs AI" intuition
- Functional state management and score tracking
- Hosted on **Vercel**

## 🧪 Purpose

This project explores the boundary between human and AI decision-making, with a focus on user interaction and game design logic.  
It is also part of my ongoing interest in agent-based systems and LLM reasoning patterns.

## 🚀 Tech Stack

- **React + TypeScript** – UI and game logic
- **Tailwind CSS** – Styling and layout
- **Vercel** – Deployment
